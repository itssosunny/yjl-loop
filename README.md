# 자기소개서 루프 실습 폴더 (`my-interview` + 그래프 4관점 + 루프 3요소)

이 폴더는 **영진전문대 특강 6회차(윈도우 환경 루프 세팅과 기본 예시 동작 확인)** 및 **7회차(내 자기소개서 정보 적용 실습)**를 위한 윈도우 에이전트 루프(`Wave Terminal` + `Antigravity CLI`) 실습 패키지입니다.

5회차 수업에서 강사가 시연했던 실제 **`my-interview` (`loops/application-writing-loop`)** 구조를 바탕으로, **루프 폴더 3요소(`실행 · 검수 · 기준표`)**와 **그래프 엔지니어링 4가지 관점**을 한눈에 보고 돌려 볼 수 있도록 구성되어 있습니다.

├── 검수.md                            # [2. 검수 (Checker)] 통과·미통과 판정 핵심 지침 (6회차 바로가기)
├── 기준표.md                          # [3. 기준표 (Rules Table)] 사람이 정한 합격 조건표 (6회차 바로가기)
├── 기본예시_정보.md                   # [기본 예시 정보] 연습용 자기소개서 STAR 경험 3건 요약

│   └── experience-episodes.md         # STAR 경험 에피소드 상세 기록 (EP-001 ~ EP-003)

    └── application-writing-loop/      # [my-interview 자기소개서 작성 루프 본체]

        ├── rules.md                   # [실행 모듈 본체] 3단계 관문(Gate A·M·W) 및 그래프 관점 1·2 규칙
        ├── verification-rules.md      # [기준표 본체] 검수 1~3층 + 그래프 4가지 관점 + 2턴 추가 조건

        ├── loop-budget.md             # 최대 재수정 횟수(관문당 3바퀴) 규칙

        ├── ssot/
        │   ├── procedure.md           # 전체 절차: 공고 분석(Gate A) → 경험 매핑(Gate M) → 초안 작성(Gate W)
        │   ├── checks.md              # [검수 모듈 본체] Gate A · Gate M · Gate W 세부 판정표 (W-BC/QM/QR)
        │   ├── writing-frameworks.md  # STAR · Why-How-What · TRACE 작성 틀 규칙
        │   ├── style-lexicon.md       # 자기소개서 금지 표현 및 권장 대체어 사전

## 2. 루프 3요소와 그래프 4가지 관점 연결표

| 구분 | 루프 폴더 내 위치 | 핵심 역할 (일상 비유) | 자기소개서 적용 |
|---|---|---|---|
| **1. 실행 (Runner)** | `실행.md` · `loops/application-writing-loop/rules.md` | 레시피대로 요리하는 **조리 담당** | 경험 정보를 읽어 자기소개서 초안을 작성하고 재수정 |
| **2. 검수 (Checker)** | `검수.md` · `loops/application-writing-loop/ssot/checks.md` | 간과 온도를 재는 **검사 담당** | 초안이 기준표 규칙을 지켰는지 검사해 `[통과]` / `[미통과]` 판정 |
| **3. 기준표 (Rules)** | `기준표.md` · `loops/application-writing-loop/verification-rules.md` | 주방 벽에 붙인 **맛 점검표** | 무엇을 합격·불합격으로 볼지 사람이 직접 정하는 규칙 목록 |
| **관점 1 (제어 흐름·관문)** | `ssot/procedure.md` (`Gate A → Gate M → Gate W`) | 사람이 도장 찍는 **출국 심사대** | 공고 분석 → 경험 매핑 → 초안 작성 순서와 사람 승인 관문 통제 |
| **관점 2 (의존성·폭발 반경)** | `runs/.../mapping.md` | 배관 하나를 바꿀 때 함께 고치는 **연쇄 범위** | 지원 직무 변경 시 함께 수정할 지원동기·역량 문단·기준표 파악 |
| **관점 3 (온톨로지·모순 검증)** | `career/canonical-fact-ledger.md` | 사실과 숫자를 대조하는 **기준 사전** | 이력서 원본과 자기소개서 초안 사이의 날짜·숫자 모순 차단 |
| **관점 4 (요구사항 추적성)** | `runs/.../mapping.md` ↔ `drafts/자기소개서.md` | 설계도와 기둥을 잇는 **1:1 연결표** | 채용공고 조건 ↔ 내 경험 ID ↔ 본문 문단 ↔ 검수 항목 1:1 추적 |

## 3. 6회차 따라 하기 4단계 안내

### 1단계 · GitHub에서 내려받고 바탕화면에 압축 풀기
1. 인터넷 브라우저에서 아래 GitHub 저장소 주소로 접속합니다 (별도 로그인 불필요).
   - **저장소 주소**: `https://github.com/itssosunny/yjl-loop`
2. 초록색 **[Code]** 버튼을 누르고 **[Download ZIP]**을 클릭합니다.
3. 내려받은 압축 파일을 윈도우 **바탕화면**으로 옮긴 뒤, 마우스 오른쪽 버튼을 눌러 **[압축 풀기]**를 실행합니다.

### 2단계 · 웨이브 터미널(Wave Terminal)로 폴더 열기
1. **Wave Terminal**을 실행하고 바탕화면의 `windows-loop-starter` 폴더를 엽니다.
2. **오른쪽 창(파일 미리보기)**에서 `실행.md`, `검수.md`, `기준표.md`, `기본예시_정보.md`와 `loops/application-writing-loop/` 폴더 안의 파일들을 클릭해 읽어 봅니다.
3. **왼쪽 창(명령 실행창)**에서 **안티그래비티 CLI(Antigravity CLI)**를 실행합니다.

### 3단계 · [1턴 실습] 기본 예시로 실행하고 검수 판정 확인하기 (15분)
1. 왼쪽 안티그래비티 CLI 창에 아래와 같이 입력합니다.
   ```text
   실행해줘
   ```
2. 오른쪽 미리보기 창에 생성된 `초안.md`(및 `runs/2026-11-18_한국국토정보공사_기획행정/drafts/자기소개서.md`)를 열어 1턴 기본 초안을 확인합니다.
3. 이어서 왼쪽 안티그래비티 CLI 창에 아래와 같이 입력합니다.
   ```text
   검수해줘
   ```
4. 오른쪽 미리보기 창에 생성된 `판정결과.md`를 열어 검수 1~3층과 그래프 4가지 관점 중 어떤 항목이 **[통과]**했고 어떤 항목이 **[미통과]**했는지 확인합니다.

### 4단계 · [2턴 실습] 기준표에 조건 1개 추가하고 다시 돌려 비교하기 (15분)
1. 오른쪽 창에서 `기준표.md`(또는 `loops/application-writing-loop/verification-rules.md`) 파일을 엽니다.
2. 맨 아래 `## [2턴 실습] 내가 직접 추가하는 검수 조건` 칸에 내가 원하는 규칙 **1줄**을 직접 적어 넣고 저장(`Ctrl + S`)합니다.
   - 예시 1: `- 각 경험 문단마다 구체적인 성과 숫자(9만 건, 15명, 1회 추가 요청 등)를 빠짐없이 포함할 것`
   - 예시 2: `- 마지막 문장에 "최선을 다하겠습니다", "열심히 일하겠습니다" 같은 막연한 다짐 표현을 쓰지 말고 직무 기여 방법을 구체적으로 적을 것`
3. 왼쪽 안티그래비티 CLI 창에서 다시 순서대로 입력합니다.
   ```text
   실행해줘
   ```
   ```text
   검수해줘
   ```
4. 내가 추가한 기준에 맞춰 `초안.md` 문장이 어떻게 구체적으로 바뀌었는지, `판정결과.md`에서 모든 항목이 **[통과]**로 바뀌었는지 비교합니다.
