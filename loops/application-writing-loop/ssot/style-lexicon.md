# Style Lexicon — 자기소개서 금지 표현 및 권장 대체어 사전 (`W-BC-5`)

자기소개서 본문(`초안.md` · `drafts/*.md`)에서 기계가 쓴 듯한 인상을 주거나 설득력을 떨어뜨리는 금지 표현과 그 대체 표현입니다.

| 쓰지 말아야 할 표현 (금지) | 대신 쓸 표현 (권장) | 이유 |
| --- | --- | --- |
| `~라고 생각합니다`, `~인 것 같습니다` | `~했습니다`, `~을 확인했습니다` | 모호한 주관적 추측 대신 실제 사실과 행동으로 단정하게 서술 |
| `다양한`, `여러 가지`, `많은` | 구체적인 개수나 항목 명시 (`3가지 기준`, `9만 건` 등) | 추상적인 수식어는 평가자에게 아무런 정보를 주지 못함 |
| `고치고`, `고쳐 나가겠습니다` | `개선하고`, `보완하겠습니다` | 문서 격식에 맞는 명확한 어휘 사용 |
| `~을 배웠습니다`, `뜻깊은 경험이었습니다` | `~한 기반을 마련했습니다`, `~체계를 구축했습니다` | 결과(Result) 문장은 내 감상이 아니라 조직과 업무에 남긴 변화로 마무리 |
| 문장 속 긴 줄표(`—`) 남발 | 쉼표(`,`) 또는 마침표(`.`)로 문장 분리 | AI가 번역투로 생성한 문장이라는 인상을 줌 |
