# Evaluator Wording — 평가자 친화 문장 변환표 (`W-BC-7`)

채용 평가자는 지원자가 "입사해서 배우겠다"는 다짐보다 **"지금까지 해 본 구체적인 방법으로 우리 기관의 업무를 어떻게 뒷받침할 것인가"**를 보고 싶어 합니다.

| 피해야 할 막연한 다짐 (Instead of) | 평가자가 신뢰하는 구체적 문장 (Use instead) | 검수 이유 (Why) |
| --- | --- | --- |
| `"입사 후에도 배우는 자세로 열심히 하겠습니다."` | `"검증된 데이터 정제와 소통 경험을 바탕으로 신뢰받는 행정 서비스를 뒷받침하겠습니다."` | 직장에서는 학생이 아니라 업무 담당자를 뽑으므로 즉시 기여할 역량으로 마무리 |
| `"최선을 다해 어떤 일이든 성실히 수행하겠습니다."` | `"기준표를 세워 오류를 걸러내고 반복 제작하는 방식으로 문서 품질을 높이겠습니다."` | 누구나 쓸 수 있는 상투어 대신 본문에서 증명한 나만의 일하는 방식을 다시 연결 |
| `"비록 관련 경험은 부족하지만 빠르게 적응하겠습니다."` | (부족하다는 변명을 쓰지 않고, 내가 가진 인접 경험 `EP-001`~`003`의 연결 강점을 바로 서술) | 스스로 약점을 선언하면 평가자의 시선이 약점에 머무름 (`W-QR-10`) |
