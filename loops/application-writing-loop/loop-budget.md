# Loop Budget — application-writing-loop

## 1. 실행 주기 및 반복 한도
- **실행 방식**: 수강생이 터미널에서 직접 실행·검수 명령을 내리는 수동 제어 방식
- **관문당 최대 재수정 횟수**: 관문별 최대 3바퀴까지 자동 재수정 후 사람이 직접 기준표(`기준표.md`) 또는 문장을 점검합니다.
- **6회차 실습 예산**: 1턴(기본 예시 초안 생성 및 검수 판정 확인, 15분) + 2턴(기준표 조건 1줄 추가 후 재실행·비교, 15분) = 총 2턴 (30분).
